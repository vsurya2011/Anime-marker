Firebase setup & tracking guide

Your Firebase web configuration is prefilled in this build. Enable Email/Password sign-in and create the Cloud Firestore database to turn on cloud sync.

1. Enable Email/Password authentication

Open Firebase Authentication → Get started → Sign-in method → enable Email/Password.

2. Create Firestore Database

Open Firestore Database → Create database. After creation, open Rules and publish the supplied firestore.rules file. These rules keep each signed-in user's anime library private to that account.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/anime/{animeId} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}

3. Deploy the PWA to Firebase Hosting

In this project folder, run npm install -g firebase-tools, then firebase login, then firebase deploy. The included firebase.json and .firebaserc are set for your project. Hosting provides the HTTPS origin required for installation and Android file sharing.

4. Install it on Android

Open your Firebase Hosting URL in Chrome on Android → ⋮ menu → Install app (or Add to Home screen). Open the installed OtakuLog app once. Then in Telegram, open a downloaded video → Share → choose OtakuLog. You can also use Import downloaded video and select a file through Android's picker.

Connect your Downloads folder for automatic library updates

In OtakuLog, tap Connect folder and choose your Android Download folder or a Telegram video folder in the Android folder picker. Allow read access. OtakuLog scans filenames when it opens, when you tap Scan now, and every 60 seconds while the app is open and visible if automatic scanning is enabled. With Automatically add confident AniList matches enabled, recognizable anime are added to the selected category and their download filenames are saved to the anime download notes. Existing anime are updated rather than duplicated. Uncertain titles remain in the review queue. You can choose whether detected episodes count as watched; this is off by default. If Chrome asks for folder access again after reopening, tap Scan now and grant access.

On browsers without the native folder picker, the website can only run a one-time folder selection. Background scanning while OtakuLog is fully closed is not available to a normal PWA; use the Telegram Share button for that case.

How episode detection works

OtakuLog reads the video filename, detects common patterns such as S02E05, Season 2 Episode 5, or Episode 5, then searches AniList for the anime poster and catalogue information. Review the match before saving. Duplicate downloaded episode records are avoided.

Downloaded does not automatically mean watched

The import checkbox is off by default. Turn it on only when you have watched that episode and want your watched progress to move forward. The imported video itself is never uploaded to Firebase; only its filename and anime/episode details are saved.

Important limits

Android file sharing requires OtakuLog to be installed as a PWA from an HTTPS website. Share-target availability depends on the app that sends the file and Android's share sheet. If Telegram does not offer the file to OtakuLog, use the manual Downloads picker. A filename can be ambiguous, so always check the detected title and episode before saving.

The Firebase web API configuration is a client identifier, not a private service-account key. Do not add service-account JSON or private credentials to this page. This tracker uses Firestore; the Realtime Database and Storage URLs are included in the config but the app does not upload videos or use those products.
